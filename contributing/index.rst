Contributing
============

Symfony is an open source, community-driven project, and there are many ways to contribute:

* :ref:`Report a Bug <reporting-a-bug>` you found (no setup needed)
* :doc:`Review and Triage </contributing/reviews>` issues and pull
  requests to help move them forward (no coding needed)
* :doc:`Contribute Code </contributing/code>` (bug fixes and features)
* :doc:`Contribute Docs </contributing/doc>` to improve the documentation
  (small fixes can be done online, without installing anything)
* :doc:`Contribute Translations </contributing/translation>` to translate the
  Symfony error and validation messages

One special case: if you found a **security issue**, don't report it publicly.
Follow the :doc:`security procedure </contributing/code/security>` instead.

New to contributing? The ``#contribs`` and ``#mentoring`` channels on the
`Symfony Slack`_ are there to help.
