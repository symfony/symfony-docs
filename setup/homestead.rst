Using Symfony with Homestead/Vagrant
====================================

.. warning::

    This article is deprecated and no longer maintained. Homestead and Vagrant
    are no longer recommended for developing Symfony applications, because
    neither tool is actively maintained anymore.

    To set up a local development environment for your Symfony application, use
    the :doc:`Symfony CLI local web server </setup/symfony_cli>` or
    :doc:`Docker </setup/docker>` instead.
